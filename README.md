## 3. How to Use the Content Library

### Browsing & Selecting Posts
1. Open [`topic-register.csv`](./topic-register.csv) in Excel, Google Sheets, or your preferred CSV viewer.
2. Filter by **Category**, **Target Audience** (CEOs, CROs, CFOs, RevOps), or **Format** (`text-only` vs `single-image`).
3. Click the relative path under `Post Filename` to open the post file.

### Publishing a Post
Each Markdown file is formatted for rapid publishing:
- **Header Metadata:** Displays the topic number, exact original title, target audience, and content objective.
- **Visual Brief (Image Posts):** Contains the image specifications, exact graphic copy, and a link to the real generated 1200x1200px PNG graphic in [`assets/post-images/`](./assets/post-images/).
- **Post Copy:** Fully written, publishable text. Zero placeholders (`[insert example]`, etc.).
- **CTA & Hashtags:** Non-salesy, thought-provoking commercial closing with 3–5 targeted B2B hashtags.
